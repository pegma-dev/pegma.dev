# Pegma logo kit

This kit is derived from the selected interwoven Pegma mark supplied as a rendered
brand-board image. The artwork has been isolated, normalized to a single color,
and refitted as compact 512-unit Bézier geometry for scalable production use.

## Primary assets

- `pegma-mark.svg` — primary standalone mark in #2C2C2C
- `pegma-mark-white.svg` — reversed standalone mark
- `pegma-lockup-horizontal.svg` — preferred wide lockup
- `pegma-lockup-stacked.svg` — preferred compact lockup
- `pegma-wordmark.svg` — outlined wordmark
- `pegma-github-avatar-dark-1024.png` — recommended GitHub organization avatar
- `pegma-social-card-1280x640.png` — general social/README preview

## Color

- Pegma Ink: `#2C2C2C`
- Pegma Slate: `#4A4A4A`
- White: `#FFFFFF`
- Off White: `#F7F8FA`

## Clear space and minimum sizes

- Keep clear space around the mark equal to at least 10% of its width.
- Use the standalone mark at 32 px or larger when possible.
- Use the horizontal lockup at 180 px wide or larger.
- Prefer the high-contrast dark avatar for GitHub and favicon use.

## Typography

The wordmark uses Manrope Bold converted to vector outlines, so no font is needed
to display the SVG files. Manrope is licensed under the SIL Open Font License;
the license is included as `licenses/Manrope-OFL.txt`.

## Notes

The source was a raster presentation rather than editable vector artwork. These
files are a clean, simplified vector reconstruction of that selected design, not
the unknown generator's original vector geometry. The SVGs contain paths only:
no embedded raster images, generated micro-curves, live text, or font dependency.
